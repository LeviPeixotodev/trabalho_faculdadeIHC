# CashControl C$+

Projeto desenvolvido como trabalho da faculdade.

O CashControl C$+ é uma interface web por enquanto apenas no front-end responsiva para controle financeiro pessoal.  
Permite visualizar saldo, contas, cartões, investimentos, relatórios e upload de extratos futuramente para implementação e analise de IA.

## Tecnologias Usadas
- Html
- Css
- Javascript
